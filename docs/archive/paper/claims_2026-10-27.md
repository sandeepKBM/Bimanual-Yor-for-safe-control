## 3. Problem and claims

**Problem.** A two-arm robot must finish a task while every executed motion keeps one certified way back to a resting state from which
the task can continue, for all object parameters it cannot yet rule out. Main case: a pan whose food amount and position are hidden.

**Headline (the one falsifiable claim).** Certifying the backup to a parameter-dependent task-ready set, instead of to a stop,
restores task completion with zero violations.
**Decisive test (proposed):** the pan task, ≥ 20 seeds with 95% CIs, against the four baselines. Falsified if ours does not complete
more often than every baseline at zero violations.

**Two pillars.** (1) Safe kinodynamic planning: the open-weight model proposes; the certificate admits. This makes "zero violations"
true. (2) Task-preserving recovery: the backup lands in S(Θ) ∩ R(Θ) (proposal §Problem formulation). This makes "restores completion" true.

Status: **proved** (proof written and checked), **measured** (sim evidence, n stated), **open** (not yet shown), **broken** (evidence against).

**Lemma 1 (supporting).** Widening Θ only removes admissions; R is antitone in Θ. Between removals certified backups stay certified,
and a VLM that only widens cannot make the robot less safe. Evidence: monotone-in-μ unit test in `nero/democ/tests/test_grasp_cert.py`;
T2 proof for the base rows.

## 7. Positioning (verified)

- **AgentChord** (arXiv 2605.11951, RSS 2026; read 10-26): GPT-5 task graph with recovery branches compiled in advance; the
  forward-progress rule is heuristic; collision/reachability only, no force or grasp checks; monitors detect failures after the fact;
  no completeness claim. Code release not confirmed.
- **van Wijk et al.** (arXiv 2610.17337; read 10-26): proves recurrence to a fixed, known set; no task-completion theorem; no uncertainty.
- **VIZ-COAST** (arXiv 2510.25548; read 10-27): VLM-extracted constraints prune task plans in a Z3 SMT task planner; continuous parts by
  COAST streams; no uncertainty. Our certificate sits below such a task layer.
- **ARMTD / ARMOUR / WAITR**: short horizon + braking fail-safe and robust mass-interval contact constraints are theirs. "Stop is always
  admitted" is passive safety (Fraichard 2007).
- Not yet read by us: Holladay et al. IJRR 2024, Prajapat et al., Enwerem et al., Vahs et al., Naveed et al., Zhang et al.
