## 3. Problem and claims

**Problem.** A two-arm robot must finish a task while every executed motion keeps one certified way back to a resting state from which
the task can continue, for all object parameters it cannot yet rule out (belief-state planning over the set Θ_t). Cases: objects whose
contents are hidden (pot, tray of mugs, closed box). The grasp is a rigid weld (ASSUMED); the risk is in how the arms carry the load.

**Headline (the one falsifiable claim).** Certifying the backup to a parameter-dependent task-ready set, instead of to a stop,
restores task completion with zero violations.
**Decisive test (proposed):** the main demo task, ≥ 20 seeds with 95% CIs, against the baselines. Falsified if ours does not complete
more often than every baseline at zero violations.

**Two pillars.** (1) Safe kinodynamic planning: the open-weight model proposes; the certificate admits. This makes "zero violations"
true. (2) Task-preserving recovery: the backup lands in S(Θ) ∩ R(Θ) (proposal §Problem formulation). This makes "restores completion"
true. Probes are one of the proposable actions: they narrow Θ_t in real time so more actions become admissible; they carry no claim.

Status: **proved** (proof written and checked), **measured** (sim evidence, n stated), **open** (not yet shown), **broken** (evidence against).

**Lemma 1 (supporting).** Widening Θ only removes admissions; R is antitone in Θ. Between removals certified backups stay certified,
and a VLM that only widens cannot make the robot less safe. Read the other way: a sound narrowing (Θ_{t+1} ⊆ Θ_t, θ* kept) leaves every
earlier certificate valid. Evidence: monotone-in-μ unit test in `nero/democ/tests/test_grasp_cert.py`; T2 proof for the base rows.

## 5. Verified results log (owner re-checked)

- **Hidden-contents carry, arm-side rows (11-02).** Dropping the claw twist cap changes no two-arm decision (static, proof under MODEL).
  Refused cells (6-mug tray ≥ 50 g per mug, box ≥ 2 kg) bind on the **left arm's payload row** under the lever load split (an
  off-centre load goes mostly to one arm). Under the ungated executor in sim (friction compensation + stiff weld, n = 20 per cell),
  those refused cells were unsafe only at box 4.5–5 kg (2/20, joint torque saturation); max object tilt grows with mass, 4.4° → 8.9°
  (limit 10°, ASSUMED). So below 4.5 kg the refusals rest on the 3 kg payload rating (spec), which the sim does not model.
- **Wrist stiction causes the tilt (11-02).** FL-MPC has no friction model; the wrists stalled under load and the box tilted up to
  18.7°; the friction compensation wrapper (gains ASSUMED) brought it to 1.85°.
- **Grasp certificate, Demo C box (10-26).** v2 0 false-safe on 256 held-out releases; rigid arms only. Out of scope since 11-02.
- **Base doorway sweep 10-26** (24 seeds, people from truth): MPPI 19/24, lattice 15/24; 0 contacts, 0 cup loss.
- **Spec certifier**: equivalent to the hard-coded certifier (2000/2000).
- **Model facts**: NERO joint torque command range ±16 Nm (MIT mode, fw ≥ 1.11), payload 3 kg (manual); the URDF 100 Nm is an
  export placeholder. Hardware gripper = YOR's Dynamixel XL430: position plus an *inferred* load reading (no current sensor, no
  current-control mode); its squeeze force is unknown (ASSUMED until measured).

## 7. Positioning (verified)

- **AgentChord** (arXiv 2605.11951, RSS 2026; read 10-26): GPT-5 task graph with recovery branches compiled in advance; the
  forward-progress rule is heuristic; collision/reachability only, no force or grasp checks; monitors detect failures after the fact;
  no completeness claim. Code release not confirmed.
- **van Wijk et al.** (arXiv 2610.17337; read 10-26): proves recurrence to a fixed, known set; no task-completion theorem; no uncertainty.
- **VIZ-COAST** (arXiv 2510.25548; read 10-27): VLM-extracted constraints prune task plans in a Z3 SMT task planner; no uncertainty.
- **ARMTD / ARMOUR / WAITR**: short horizon + braking fail-safe and robust mass-interval contact constraints are theirs. "Stop is always
  admitted" is passive safety (Fraichard 2007).
- Belief-narrowing components to cite, not competitors (abstracts only, 11-02): Zhang, Zhou & Vasudevan, provably-safe online system
  identification (arXiv 2504.21486); Real2Sim-BT (2601.08454); RigPI (2606.25212); Phys2Real (2510.11689). Robust transport over all
  inertial parameters: Heins & Schoellig (2411.07079).
- Not yet read by us: Holladay et al. IJRR 2024, Prajapat et al., Enwerem et al., Vahs et al., Naveed et al.
